📖 Edge AI 道路安全辨識系統操作手冊

從 Roboflow 資料集標註、Colab GPU 模型訓練到 GitHub Pages 純前端離線部署完整指南

第一階段：Roboflow 影像標註與資料擴增
1. 建立專案與資料標註 (Annotation)
  • 登入 Roboflow，建立 Object Detection（物件偵測）專案。
  • 設定目標類別名稱（例如：crosswalk 斑馬線、traffic light 紅綠燈）。
  • 使用 Bounding Box 緊密框選目標物體邊緣，避免包含過多無關背景雜訊。
  • 資料集切分比例建議設定為：70% Train（訓練集）/ 20% Valid（驗證集）/ 10% Test（測試集）。
2. 預處理 (Preprocessing) 與資料擴增 (Augmentation)
⚙️ Preprocessing 必選設定
  • Auto-Orient：自動修正手機拍攝 EXIF 旋轉方向。
  • Resize (Stretch to 640x640)：統一縮放為 YOLO 標準輸入尺寸。
✨ Augmentation 推薦參數 (Outputs = 3)
  • Horizontal Flip：水平翻轉，適應雙向車道視角。
  • Brightness (±15%)：整體明暗平移，模擬陰天與樹蔭。
  • Exposure (±15%)：曝光倍數調整，模擬烈日眩光。
  • Blur (Up to 2.5px)：模擬行車移動時的動態模糊。
  • ⚠️ 注意：切勿勾選 Mosaic（避免切斷斑馬線連續條紋特徵）。

設定完成後點擊 Generate ➔ Export Dataset，格式選擇 YOLOv8 / YOLO11 / YOLO26 (PyTorch) 並複製下載程式碼。

第二階段：Google Colab 雲端 GPU 訓練與轉檔 ONNX
⚡ 啟動硬體加速：開啟 Google Colab 後，點擊上方選單「執行階段 ➔ 變更執行階段類型」，務必選擇 T4 GPU 再開始執行。
1. 安裝 Ultralytics 套件並貼上 Roboflow 資料集程式碼
!pip install ultralytics roboflow

# 在下方貼上你從 Roboflow 複製的下載程式碼（包含 API Key）
2. 啟動模型訓練 (以輕量化 YOLO26n 為例)
from ultralytics import YOLO

# 載入預訓練權重（可依需求選用 yolo26n.pt 或 yolov8n.pt）
model = YOLO('yolo26n.pt')

# 開始訓練 50 輪，輸入解析度 640x640
model.train(data='/content/datasets/data.yaml', epochs=50, imgsz=640, name='road_safety')
3. 匯出為網頁專用 ONNX 通用格式
# 載入訓練完成的最佳權重並匯出為 best.onnx
best_model = YOLO('/content/runs/detect/road_safety/weights/best.pt')
best_model.export(format='onnx', imgsz=640)

執行完畢後，至左側檔案資料夾 runs/detect/road_safety/weights/ 下載 best.onnx 至電腦。

第三階段：前端網頁整合與 GitHub Pages 部署
1. 檔案資料夾結構

請確保以下三個檔案位於同一個專案根目錄下：

📁 road-safety-ai/
 ├── 📄 index.html       (主辨識測試網頁)
 ├── 📄 crosswalk.html   (本操作教學手冊)
 └── 🧠 best.onnx        (從 Colab 匯出的 AI 模型檔)
2. 本機測試指令（避開瀏覽器 CORS 安全性阻擋）

請勿直接雙擊開啟 index.html（file:// 協定會阻擋讀取模型），請在專案資料夾開啟終端機執行：

python -m http.server 8000

開啟瀏覽器前往 http://localhost:8000 即可進行本機離線推理測試。

3. 上傳 GitHub Pages 免費公開發布
  1. 登入 GitHub 建立新的公開倉庫（Public Repository），上傳 index.html、crosswalk.html 與 best.onnx。
  2. 進入倉庫的 Settings ➔ Pages，將 Branch 設為 main 並點擊 Save。
  3. 切換至頂部 Actions 頁籤，等待 pages-build-deployment 轉為綠色勾勾 ✅ 即正式上線。
第四階段：常見問題與現場排錯指南 (Troubleshooting)
異常現象 常見原因 標準解決方案
畫面顯示「模型載入失敗」 直接雙擊開啟 HTML 檔案（CORS 阻擋），或 best.onnx 檔名/路徑不符。 確認 best.onnx 與 index.html 在同一層目錄，並透過本機伺服器或 GitHub Pages 網址開啟。
標籤名稱顯示顛倒（紅綠燈變斑馬線） 網頁內的 CLASSES 陣列順序與模型訓練時的 data.yaml 相反。 開啟 index.html 修改【模型區 1】的 CLASSES 陣列順序即可。
遠處紅綠燈或斑馬線漏抓 信心度門檻設太高，或小物件樣本不足。 將【模型區 3】的 confThreshold 調降至 0.25 ~ 0.35 測試效果。
網頁出現 404 或手機選單無法展開 GitHub Pages 尚未部署完成、index.html 未放根目錄，或漏載 Bootstrap JS。 檢查 GitHub Actions 綠色勾勾、確認 bootstrap.bundle.min.js 已引入，並用手機無痕視窗重整。
